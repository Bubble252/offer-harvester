# 用户流程设计

## 总体流程

第一版 Web UI 的主流程如下：

```text
进入工作台
-> 创建/导入学生资料
-> 添加真实导师资料
-> 创建申请目标
-> 查看匹配分析
-> 生成申请材料
-> 准备面试
-> 生成 PPT 大纲
-> 更新申请状态
```

MVP 以单用户本地工作台为主，不做登录和多用户。

## 页面 1：首页 / 工作台

### 页面目标

让用户快速看到当前申请进度和下一步任务。

### 主要区域

- 学生资料状态
- 目标数量
- 待联系导师
- 待补充资料
- 最近生成材料
- 申请状态统计

### 用户动作

- 上传学生资料
- 添加导师资料
- 创建申请目标
- 进入目标池
- 查看申请看板

### 空状态

如果用户第一次进入：

```text
请先上传你的保研申请资料，系统会生成学生画像。
```

按钮：

- `上传学生资料`
- `粘贴资料文本`

## 页面 2：学生资料页

### 页面目标

建立可编辑、可追溯的学生画像。

### 用户输入

- 上传简历/PDF
- 粘贴科研项目介绍
- 手动填写 GPA、排名、英语成绩
- 手动填写论文、竞赛、奖项

### 系统展示

- 基础信息
- 教育背景
- GPA / 排名
- 科研兴趣
- 项目经历
- 论文成果
- 竞赛奖项
- 技能关键词
- 风险项

### 交互要求

- 每个字段都允许用户编辑
- 不确定字段标记为“需确认”
- 用户确认后写入 profile

### 下一步

按钮：

- `保存学生画像`
- `添加导师资料`

## 页面 3：导师资料页

### 页面目标

从真实来源构建导师画像。

### 用户输入

- 导师主页 URL
- 实验室主页 URL
- 招生通知 URL
- 论文主页 URL
- 手动粘贴资料正文

### 抓取流程

```text
用户输入 URL
-> 后端抓取网页正文
-> 成功：展示抓取文本和解析结果
-> 失败：提示用户粘贴正文
-> 保存 AdvisorSource
-> 解析 AdvisorProfile
```

### 系统展示

- 抓取状态：成功 / 失败 / 手动
- 来源标题
- 来源 URL
- 清洗后的正文
- 导师姓名
- 学校学院
- 职称
- 实验室
- 研究方向
- 近期关注点
- 招生类型
- 联系邮箱

### 交互要求

- 用户可以编辑解析结果
- 用户可以标记来源是否可信
- 系统必须保留原始来源

### 下一步

按钮：

- `保存导师画像`
- `创建申请目标`

## 页面 4：目标池页

### 页面目标

管理多个保研硕博申请目标。

### 列表字段

- 导师/项目名称
- 学校学院
- 申请类型
- 截止日期
- 当前状态
- 匹配等级
- 下一步行动

### 筛选

- 状态
- 学校
- 申请类型
- 匹配等级

### 用户动作

- 新建目标
- 进入目标详情
- 更新状态
- 删除草稿目标

## 页面 5：目标详情页

### 页面目标

围绕单个导师/项目完成申请准备。

### 主要区域

- 导师摘要
- 目标信息
- 来源资料
- 匹配分析
- 已生成材料
- 当前状态
- 下一步行动

### 用户动作

- 运行匹配分析
- 生成套磁邮件
- 生成面试问题
- 生成 PPT 大纲
- 更新申请状态

## 页面 6：匹配分析页

### 页面目标

解释学生为什么适合或不适合这个导师/项目。

### 输出结构

- 总体匹配等级
- 简短结论
- 匹配优势
- 主要短板
- 风险提示
- 推荐行动
- 证据来源

### 匹配等级

- `strong_fit`
- `reasonable_fit`
- `weak_fit`
- `unknown`

### 展示要求

- 不展示录取概率
- 不使用“必上”“稳录”等表达
- 每条结论都展示证据来源

### 用户动作

- 复制分析结果
- 重新生成
- 进入材料生成

## 页面 7：材料生成页

### 页面目标

生成和编辑中文申请材料。

### 材料类型

- 中文套磁邮件
- 中文个人陈述大纲
- 中文研究计划大纲
- 中文科研项目介绍

MVP 必须完成：

- 中文套磁邮件

P1 完成：

- 个人陈述大纲
- 研究计划大纲

### 用户动作

- 选择材料类型
- 选择语气：正式 / 简洁 / 稳妥
- 生成草稿
- 编辑草稿
- 保存版本
- 下载 Markdown

### 质量提示

系统需要显示：

- 使用了哪些学生经历
- 使用了哪些导师来源
- 是否存在夸大风险
- 是否缺少关键材料

## 页面 8：面试准备页

### 页面目标

帮助学生准备导师面谈、夏令营面试、预推免面试。

### 输出内容

- 自我介绍问题
- 科研项目深挖问题
- 导师方向相关问题
- 简历真实性问题
- 短板解释问题
- 可以反问导师的问题

### 用户动作

- 生成问题清单
- 标记已准备
- 添加自己的答案
- 导出 Markdown

### 约束

- 答案不能编造经历
- 对短板只能给 bridge answer，不包装成不存在的优势

## 页面 9：PPT 大纲页

### 页面目标

生成面试展示 PPT 的结构和每页内容。

### 用户输入

- 目标导师
- 展示时长：3 分钟 / 5 分钟
- 展示重点：科研项目 / 综合介绍 / 研究计划

### MVP 输出

5 页中文 PPT 大纲：

```text
1. 封面
2. 教育背景与能力概览
3. 代表科研/项目经历
4. 与目标导师方向的匹配
5. 未来研究计划与结束页
```

每页输出：

- 标题
- 页面目的
- 核心要点
- 建议讲稿
- 证据来源

### 后续扩展

接入演示文稿生成能力后增加：

- 上传参考 PPT 模板
- 生成 PPTX
- WebSocket 进度
- 下载 PPTX

## 页面 10：申请状态页

### 页面目标

追踪多个申请目标状态。

### 状态

```text
draft
researching
ready_to_contact
contacted
replied
materials_preparing
submitted
shortlisted
interview_scheduled
interview_done
accepted
rejected
withdrawn
```

### 展示字段

- 目标名称
- 导师
- 学校
- 当前状态
- 最后联系时间
- 下一步行动
- 备注

### 用户动作

- 更新状态
- 添加备注
- 设置下一步行动
- 导出看板

## 异常流程

### URL 抓取失败

```text
系统提示：无法自动抓取该页面，请粘贴网页正文。
用户粘贴正文
系统保存 source_type=manual_text, fetch_status=manual
继续解析导师画像
```

### 学生资料不足

```text
系统提示：当前资料不足以生成稳妥匹配分析。
列出缺失字段：GPA、科研项目、排名等
允许用户继续，但匹配等级可能为 unknown
```

### 导师资料不足

```text
系统提示：导师来源不足，无法判断近期方向。
建议补充：导师主页、实验室主页、近年论文链接
允许保存为 unknown
```

### LLM 生成失败

```text
系统提示：生成失败，请稍后重试或检查模型配置。
保留用户输入和目标状态
```

### 演示文稿生成能力未配置

```text
系统仍可生成 PPT 大纲。
PPTX 生成功能显示为“未配置”。
```

## 首次 Demo 流程

推荐演示路线：

```text
1. 进入首页
2. 上传匿名学生资料
3. 查看并确认学生画像
4. 输入导师主页 URL
5. 展示 URL 抓取成功或手动粘贴兜底
6. 保存导师画像
7. 创建直博申请目标
8. 运行匹配分析
9. 生成中文套磁邮件
10. 生成面试问题
11. 生成 5 页 PPT 大纲
12. 更新申请状态为 contacted
```

## 第一版 UI 原则

- 中文界面
- 业务流程优先，不做复杂视觉装饰
- 每一步都能返回修改
- 所有生成内容可编辑
- 所有重要结论可追溯
- 不自动发送任何对外邮件
- 不展示录取概率
