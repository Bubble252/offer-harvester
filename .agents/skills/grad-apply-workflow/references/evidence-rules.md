# Evidence Rules

## Student Facts

Supported by:

- Local uploaded or pasted documents
- User-confirmed structured profile fields
- User-confirmed web supplements

Never let unconfirmed web supplements overwrite local student evidence.

## Advisor Facts

Supported by:

- Advisor homepage
- Lab homepage
- Admission notice
- Publication page
- School faculty profile
- Manual pasted public text

Advisor conclusions must retain source IDs or source snippets.

## Generated Material Claims

Audit claims in these categories:

- Grades, GPA, rank
- Papers, submissions, awards
- Research project details
- Skills and tools
- Advisor research directions
- Recruiting status and admission requirements
- Student-advisor fit claims

Unsupported factual claims must be revised, removed, or sent for user confirmation.
