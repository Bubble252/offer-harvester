# Contact Email Coach

1. Collect one target advisor, the profile candidate, and source/evidence references.
2. Select one mode: new, rewrite, advisor-alignment, reduce-exaggeration, or follow-up.
3. Reuse the Offer Harvester `MaterialDraftAgent -> MaterialReviewAgent -> EvidenceAuditAgent` workflow.
4. Show the draft, review issues, unsupported claims, unconfirmed fields, and evidence refs together.
5. Export or save only a candidate. Require the user to review and send it themselves.

Never send email, infer admission probability, or write confirmed profile/tracker state.

## 中文说明

1. 收集一个目标导师、profile 候选和来源/证据引用。
2. 选择一种模式：新写、改写、按导师方向强化、降低夸大或 follow-up。
3. 复用 Offer Harvester 的 `MaterialDraftAgent -> MaterialReviewAgent -> EvidenceAuditAgent` 工作流。
4. 同时展示草稿、审查问题、unsupported claim、未确认字段和 evidence refs。
5. 只导出或保存 candidate；由用户自行复核并决定是否发送。

不得发送邮件、推断录取概率或写入 confirmed profile/tracker 状态。
