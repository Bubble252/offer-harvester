# Recommendation Letter Helper

1. Identify the recommender, intended program, deadline, and supplied student evidence.
2. Separate a request email, evidence packet, and recommender-perspective reference draft.
3. Link every achievement to a source and flag unconfirmed or rejected profile fields.
4. Run material review and EvidenceAudit before presenting the candidate.
5. Label recommender-perspective text as reference-only; the recommender must rewrite, approve, and submit it.

Never impersonate a recommender, send a request, submit a letter, or promote candidate facts without confirmation.

## 中文说明

1. 确认推荐人、目标项目、截止日期和学生证据。
2. 区分请求邮件、素材包和推荐人视角参考草稿。
3. 每项亮点均链接来源，并标记未确认或 rejected profile 字段。
4. 展示 candidate 前先运行材料审查与 EvidenceAudit。
5. 推荐人视角文本必须标为 reference-only；推荐人需要自行改写、确认和提交。

不得冒充推荐人、发送请求、提交推荐信，或在未经确认时提升候选事实。
